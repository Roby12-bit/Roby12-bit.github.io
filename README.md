# Personal Portfolio Website

Welcome to the repository of my personal portfolio website.

This website serves as an interactive showcase of my journey as a **Computer Engineering** student. It highlights my technical projects, core skills, and academic background in software engineering, algorithms, embedded systems, and networking.

**Live Demo:** [roby12-bit.github.io](https://roby12-bit.github.io)

---

## Features

- **Responsive & Modern UI:** Designed with a clean, mobile-first approach ensuring smooth layout adaptations across all screen sizes.
- **Interactive Navigation:** Includes custom drop-down menus, floating quick-action buttons, and smooth scrolling for an optimal user experience.
- **Projects Showcase:** Highlights hands-on software applications, including **Jarvis** (Python voice assistant for embedded systems/Raspberry Pi), C++ algorithms & data structures, web development projects, and network configuration labs.
- **Contact & Links:** Quick access to my GitHub profile, resume, and professional contact information.

---

## Tech Stack & Tools

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design & Layout:** Custom CSS Flexbox/Grid, Responsive Media Queries, Interactive Animations
- **Hosting & Version Control:** Git, GitHub, GitHub Pages
